QC aliquot volumes — standardisation against proven volumes

For lab managers. Volumes and parameter counts only, no cost. The target in this document is the lowest volume another lab in the network already runs successfully for the same material.
PROVEN means a lab is already doing it The least volume is simply the lowest figure recorded for that material across BLR 1, BLR 2, MUM, HYD, GGN, NOA and NRL. No calculation, no assumption — a site is running it today. Columns marked CALCULATED are shown for reference only. Those come from adding up published aspiration volumes plus dead volume, and that work is still being finalised. Do not act on the calculated column yet.

Before changing any SOP 1. A lower volume proven at another lab is evidence, not authorisation. Where you run more parameters than the lab proving the least, the amber note flags it — those eight lines need a parallel run first.
2. Reducing the aliquot makes a vial last longer. That only helps if the vial is still finished inside its open-vial stability window. Where a part-used vial is already discarded on time, a smaller aliquot changes nothing.
3. Every reduction needs a documented parallel run and lab-head sign-off before it becomes SOP.
4. Ignore the calculated columns for now. They are shown so you can see where that work is heading, but the dead volume behind them is not yet confirmed and two catalogue values are known to be wrong.
